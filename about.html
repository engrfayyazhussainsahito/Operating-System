About

About and contributing

This is a free, open, 16-week undergraduate Operating Systems course. It is meant to be learnable from these pages alone. You need C, basic data structures and a Linux shell.

Why this site is structured this way

The layout (phases, weekly pages with objectives, demos, labs, graded exercises with collapsed solutions, a syllabus and a glossary) follows the shape of the open course Deep Learning for Dummies. All text, code, figures and simulators here are original to this course.

Contributing

  • Fix typos or report technical errors.
  • Add exercises with worked solutions.
  • Build or improve a simulator in src/demos.js.
  • Translate a chapter.

Before opening a pull request: write in your own words, check every number by running the code or the simulator, avoid em dashes, and disclose any AI assistance.

Repository layout

PathContents
content/week-NN.mdOne Markdown chapter per week, with front matter
content/glossary-*.txtLines of the form Term | week | definition
src/style.css, src/app.jsTheme and page behaviour
src/demos.jsAll interactive simulators
build.pyThe generator (Python 3 and the markdown package)
site/Generated output, do not edit by hand
pip install markdown
python3 build.py
python3 -m http.server -d site 8000

The output is plain HTML, CSS and JavaScript with relative links, so it works on GitHub Pages, Netlify or any static host, including from a sub-path.
