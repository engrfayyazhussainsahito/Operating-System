Learn operating systems by watching them work.

A free undergraduate course where every idea gets an analogy, a precise definition, a worked trace, code you can run on Linux, and a simulator or 3D model you can poke at. Every exercise has a worked solution.

How to study this course

  1. Predict, then pressEvery demo has a question ahead of it. Write your answer first, then run it.
  2. Trace on paperGantt charts, page tables and Banker matrices are exam skills. Work the exercise by hand, then open the solution.
  3. Run the codeLabs need only gcc on Linux or WSL. Change a line, break it on purpose, read the error.
  4. Look things upSearch with the / key. Every glossary term links to the week that defines it.

Progress is saved in your browser only. No account, no tracking.

Learning path

Phase 1Foundations

01

Introduction, OS Structure and System Calls

What an operating system is, how hardware protects it from programs, how programs ask it for services through system calls, and how its internals can be organised and booted.

2 interactive
02

Processes

What a process is, how the operating system represents it with a process control block, how it moves between states, how the CPU is switched between processes, and how Unix creates, runs and reaps them with fork, exec and wait.

2 interactive
03

Threads and Interprocess Communication

Why a process may contain several threads, how threads are implemented and programmed with POSIX threads, what limits their speedup, and how separate processes exchange data through pipes, shared memory and signals.

2 interactive
04

CPU Scheduling

How the OS decides which ready thread gets the CPU next, from FCFS and shortest-job-first through round robin and multilevel feedback queues to Linux's fair scheduler and real-time policies, with exact worked Gantt traces.

2 interactive

Phase 2Concurrency and Deadlocks

05

Synchronization I

Why concurrent updates to shared data go wrong, how the critical section problem is defined, and the tools that solve it: atomic instructions, spinlocks, mutexes, semaphores and condition variables.

2 interactive
06

Synchronization II

The classic synchronization problems (bounded buffer, readers-writers, dining philosophers), monitors and condition variables as a higher-level tool, and a ten-item review checklist for the midterm.

2 interactive
07

Deadlocks

When threads wait forever for each other's resources. The four necessary conditions, resource-allocation graphs, prevention by lock ordering, avoidance with the Banker's algorithm (fully traced), detection with wait-for graphs, and recovery.

2 interactive

Phase 3Memory

08

Main Memory

How the OS and the memory management unit share RAM among processes: base and limit registers, contiguous allocation and fragmentation, paging and page tables, TLBs, multilevel page tables, and segmentation, with worked address translations and the Midterm.

3 interactive
09

Virtual Memory

How an OS lets programs use more memory than exists by loading pages only when they are touched, how fork stays cheap with copy-on-write, and how the kernel and malloc hand out memory.

2 interactive
10

Page Replacement, Frame Allocation and Thrashing

What the OS does when RAM is full and a page fault needs a frame: the FIFO, LRU, OPT and Clock replacement algorithms with worked traces, Belady's anomaly, how frames are divided among processes, and why too much multiprogramming causes thrashing.

1 interactive

Phase 4Storage, Protection and Modern Systems

11

Mass Storage: Disks, SSDs, Scheduling and RAID

How hard disks and flash drives actually store and retrieve data, why seek and rotation dominate disk performance, how the OS orders requests with FCFS, SSTF, SCAN and LOOK, and how RAID combines drives for speed and fault tolerance.

4 interactive
12

File Systems I: Interface and Implementation

What a file and a directory are, how the kernel tracks open files, how blocks are allocated (contiguous, linked, FAT, indexed), how Unix inodes reach terabytes with a few pointers, and how links, free-space maps, mounting and the VFS layer fit together.

2 interactive
13

File Systems II: Journaling, Caching and the I/O Subsystem

How file systems survive crashes (fsck, journaling, copy-on-write, log-structured designs), how the kernel caches and schedules disk traffic, and how the I/O subsystem talks to devices through polling, interrupts, DMA and drivers.

14

Protection and Security

How an operating system decides who may do what: domains and rings, the access matrix, ACLs and capabilities, Unix permissions, setuid and umask, least privilege, authentication, memory-safety defenses, seccomp, the confused deputy and TOCTOU races.

1 interactive
15

Virtualization, Containers and Case Studies: Linux and Windows

How one machine pretends to be many (hypervisors, trap-and-emulate, binary translation, paravirtualization, VT-x and nested page tables), how containers get a similar effect with Linux namespaces and cgroups, and how Linux and Windows put the course ideas together.

16

Review, Projects and Final Exam

A map of the whole course, a cumulative cheat sheet of equations and algorithms, a debugging checklist, guidance for the final project, pointers for studying real kernels, and a 28-question practice final with short solutions.
